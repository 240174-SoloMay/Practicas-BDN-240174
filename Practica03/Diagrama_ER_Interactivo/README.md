# Diagrama ER interactivo

Abre `index.html` en un navegador moderno. Para que el navegador cargue `data/schema.json`, lo más fiable es servir esta carpeta desde un servidor estático local (por ejemplo `npx serve .` ejecutado dentro de esta carpeta); la aplicación no necesita conexión a base de datos ni dependencias externas.

Controles: rueda del ratón para zoom; arrastrar el fondo para desplazar; arrastrar el encabezado de una entidad para moverla; seleccionar tarjeta para ver detalles; buscar nombre/columna; elegir grupo; usar Ajustar, Restablecer y Mostrar todas. El botón de flujo pausa y reanuda los indicadores animados. El slider ajusta velocidad.

La animación es una simulación visual de las FK explícitas. Fuente única: `Practica03/backups/respaldo05_11_26.sql`, SHA-256 `B4E81FD8411D2A859E3A8A261CE57EACF4BCC628E8C9B92F1DE2B101CA2206F9`. No se ejecutó SQL.
